系統硬性限制與不支援項目

⚠️ 導入前必讀（環境與技術限制）：
本系統深度介入 RPG Maker MZ 底層紋理渲染管線與本地檔案系統，以下環境與機能明確不支援，請於評估專案架構時務必留意。
  • 不支援手機端（Android / iOS）與純網頁瀏覽器（Web / HTML5）：
    核心引擎依賴 Node.js 的 fs 與 path 模組即時檢索圖集 JSON 與散圖狀態，僅支援 Windows / macOS 桌面端（NW.js 環境），無法打包輸出為手機 App 或純網頁遊戲。
  • 遊戲資源加密（Encryption）尚未完整測試：
    打包部署（Deployment）時若勾選「加密圖像檔案（.rpgmvp / .png_）」，目前尚未經過完整實機測試，可能會在多紋理聚合或預讀階段產生未知讀取異常。建議發布前務必自行實測或保持圖片不加密。
  • 不支援旋轉切片（rotated: true）與陣列格式 JSON：
    使用 Aseprite 或 TexturePacker 匯出精靈表時，必須關閉旋轉（Allow Rotation），並採用標準 Hash（物件鍵值對）格式輸出 JSON。
  • 不支援 CPM 原生交叉淡化（CrossFadeFrame）：
    圖集透過單一圖層動態抽換大圖紋理與裁切框實現，無法同時對同一圖層的兩個圖集切片執行原生交叉淡化混合效果。
  • 空白幀代碼禁止設為 0 或 1：
    自訂空白幀代碼（BlankFrameCode，預設 999）支援負數（如 -1）與三位數以上代碼，但為避免與常規差分編號衝突，嚴禁設為 0 或 1。

システム制限事項・非対応機能

⚠️ 導入前の重要確認事項：
本システムは RPG Maker MZ の描画パイプラインおよびローカルファイルシステムに直接アクセスします。以下の環境・機能には対応しておりませんので、導入前に必ずご確認ください。
  • スマートフォン（Android / iOS）および Web ブラウザ版（HTML5）非対応：
    コアエンジンは Node.js の fs および path モジュールを使用して JSON と画像ファイルを直接スキャンするため、Windows / macOS デスクトップ版（NW.js 環境）専用となります。スマホアプリやブラウザ公開には対応していません。
  • 画像ファイルの暗号化（Encryption）は未検証：
    デプロイメント時に「画像ファイルを暗号化する（.rpgmvp / .png_）」を有効にした場合の動作は現在未検証です。マルチテクスチャ結合やプリロード時に予期せぬ読み込みエラーが発生する可能性があります。
  • スプライト回転（rotated: true）および配列形式 JSON 非対応：
    Aseprite 等でスプライトシートを出力する際は、必ず回転（Allow Rotation）を無効にし、Hash（オブジェクト）形式で JSON を出力してください。
  • CPM 標準のクロスフェード（CrossFadeFrame）非対応：
    単一スプライトのテクスチャとフレーム領域を動的に切り替える仕組み上、同一レイヤー内でのクロスフェード合成には対応していません。
  • 空白フレームコードへの 0・1 指定禁止：
    空白フレームコード（BlankFrameCode、初期値 999）には -1 などの負数も指定可能ですが、通常の差分番号との競合を防ぐため 0 および 1 の設定は禁止されています。

Unsupported Features & Hard Limitations

⚠️ Mandatory Pre-Integration Notice:
This system hooks directly into RPG Maker MZ's rendering pipeline and local file system. The following environments and features are strictly unsupported.
  • No Mobile (Android / iOS) or Pure Web Browser (HTML5) Support:
    The core engine relies on Node.js fs and path modules to resolve atlas JSONs and loose files at runtime. It only supports Windows / macOS desktop builds (NW.js) and cannot run in mobile wrappers or standard web browsers.
  • Asset Encryption (.rpgmvp / .png_) Untested:
    Deploying with RPG Maker MZ's image encryption enabled has not been thoroughly tested and may cause unexpected loading failures during multi-texture aggregation or preloading.
  • No Rotated Sprites (rotated: true) or Array-Format JSON:
    When exporting sprite sheets from Aseprite or TexturePacker, Allow Rotation must be disabled, and JSON data must be exported in standard Hash (object) format.
  • No CPM Native Cross-Fade (CrossFadeFrame):
    Because atlas rendering dynamically swaps texture regions on a single sprite, native cross-fade blending between two atlas frames on the same layer is not supported.
  • Blank Frame Code Cannot Be 0 or 1:
    Custom blank tokens (BlankFrameCode, default 999) accept negative values like -1, but 0 and 1 are prohibited to prevent collisions with standard variation indices.
